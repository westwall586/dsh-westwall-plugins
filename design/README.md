# 验收示例

`showcase.md` 是可交互 Markdown 的固定验收样例，用来一眼看出各类组件的渲染效果。以后每加一个组件或改一次样式，都用这份文档在 Web 预览里点一遍，并把新组件的样例补进对应章节。

## 怎么用

1. 用 Web profile 起服务，打开本仓库为工作区。
2. 在文件树里打开 `design/showcase.md`。
3. 按章节从上到下点：Callout 的七族颜色、代码块的换行开关、宽表格的横向滚动、图片放大、Mermaid 与导图的渲染和全屏、写坏的图与代码的回退。
4. 明暗两种主题各看一次，窄栏与全屏两种宽度各看一次。

## 维护规则

- 这份文档只追加，不删旧的样例。已有样例代表一次验收结论，删掉就失去对照。
- 每个组件至少给三种样例：正常、边界（空标题、超长行、超宽表）、失败（语法写坏）。失败样例必须能在页面上看出「回退成源码」而不是白屏。
- 新增组件先往这里补样例，再写实现。样例就是验收清单。
- 图片放 `design/assets/`，用相对路径引用。

## 章节

| 章节 | 覆盖的组件 |
|---|---|
| 标题与行内 | 标题层级、粗体、斜体、删除线、行内代码、链接、硬换行 |
| 列表 | 无序、有序、任务、嵌套 |
| 引用 | 普通引用、列表内的引用 |
| Callout | 13 个规范类型、七族颜色、空标题、未知类型、折叠语法、列表内 |
| 代码块 | 语言标签、超长行换行开关、无语言、空行 |
| 表格 | 对齐、超宽表的横向滚动 |
| 图片 | 本地图、放大与关闭 |
| Mermaid | 正常图、写坏的图、全屏缩放 |
| 思维导图 | Markmap 大纲、折叠层级、全屏缩放 |
| 排版 | 阅读宽度、中文标点、长段落 |
| 数学 | 行内与行间（等 P4e 落地后启用） |
