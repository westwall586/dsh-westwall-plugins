范围

这条流水线把用户问题变成一组排序后的段落。本次评审覆盖本季度有变化的两段：摄取与排序。

已知缺口

  • 分块只按空行切分。
  • 排序把时间当作并列时的次级键。
  • 删除会重建整个文件的索引。

索引器说明

这段命令在暂存桶上运行索引器，并把打印出的数量与上一次运行对比。

text
# 对暂存桶运行索引器 node indexer.js --bucket staging # 把上面的数量与上次运行对比
