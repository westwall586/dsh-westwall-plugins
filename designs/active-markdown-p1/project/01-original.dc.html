Retrieval Pipeline Review

The pipeline turns a user question into a ranked set of passages. This review covers the two stages that changed this quarter — ingestion and ranking — and records what we decided to leave alone.

Scope

  • Ingestion: how a workspace file becomes a chunk
  • Ranking: how chunks are ordered for a given question
  • Everything after the first answer: out of scope
