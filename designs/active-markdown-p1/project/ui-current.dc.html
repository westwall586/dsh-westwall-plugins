Active Markdown P2b 技术方案：块级更新标记

2026-11-18 · 设计定稿 · Web 实机复核通过

3. 基线

3.1 什么是基线

基线是最近一次已发送、且留下了全文快照的审阅轮次。之后打开文档时，拿这份快照和最新全文做块级 diff。

只标记本次批注提交后仍存在且被更新的段落与组件，并在目录里标出被更新的章节。

3.2 为什么最新一轮快照缺失时不回退

如果最新一轮没有快照，就不显示更新，而不是退回到更早的轮次。否则基线会悄悄变旧。

4. Host 接口

只加一个只读接口：reviewLatest 返回最近一次已发送轮次的快照与元数据。

5. 块级 diff

5.1 块内容键

块内容键按渲染语义生成：折叠空白、忽略列表符号与围栏风格；文字、链接地址、图片与强调的变化都会换键。这里的「渲染语义」需要一条可读的定义。
