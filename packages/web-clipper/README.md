# 网页剪藏 使用手册

> **状态：草稿。** 尚未发布到 npm；用本地目录或 GitHub 固定 commit 安装。只支持 DSH 桌面版。

在侧栏浏览器读长网页时，想把整页交给 Agent，复制粘贴既费事又容易丢格式。网页剪藏把当前页提取成 Markdown 附件放进会话输入框，Agent 可以直接读全文；提取不出正文时保存整页 HTML。附件只加入输入框，不会自动发送。

同时，插件会在本机保存一份可直接打开的可读副本，默认放在系统临时目录。会话里的附件仍由 DSH 持久保存；副本是给你自己查看、整理和用其他工具处理的。副本目录可以在插件设置里改，也可以一键打开。

## 快速开始

1. 安装插件。桌面版在左侧栏 → **插件** → **Add plugin** 选择本目录，或执行下面的命令：

```sh
dsh plugin --profile <profile> add link:/绝对路径/packages/web-clipper
```

2. 重启 DSH。
3. 打开右侧栏的浏览器标签，访问任意网页。
4. 在标签菜单里点「添加到会话」，或点输入框左侧的加页图标，预期输入框附件栏出现一个以时间戳加页面标题命名的 `.md` 文件。

## 配置

打开左侧栏 → **插件** → **网页剪藏**，在插件详情页的配置区可以设置副本目录。随「资讯工作台」安装时，配置入口在资讯工作台详情页的「网页剪藏」行。

| 设置 | 默认 | 说明 |
|---|---|---|
| 副本目录 | 空 | 留空时写入系统临时目录下的 `dsh-web-clipper`；填绝对路径则写入该目录 |

- 「选择文件夹」打开系统目录选择器，选中后立即保存。
- 「打开文件夹」会先创建目录，再在 Finder（macOS）或文件资源管理器（Windows）中打开它。默认目录和自定义目录都可以打开。
- 「恢复默认」清空设置，回到系统临时目录。
- 目录必须是绝对路径。相对路径会被拒绝。
- 副本保存失败不会阻断会话附件，只会在右下角提示失败原因。

会话附件本身仍存放在 DSH 的附件库里，不会被这个设置搬走。这个设置只控制额外那份可读副本的位置。

## 日常使用

### 从标签菜单添加

在侧栏浏览器的标签上打开菜单，点「添加到会话」。菜单会关闭，当前标签获得焦点，随后页面内容作为附件进入输入框。页面还在加载时，这个菜单项会变灰，加载完成后才能点。

### 从输入框按钮添加

输入框左侧的加页按钮只在当前会话至少有一个浏览器标签时出现。点击后取当前浏览器页；如果当前标签不是浏览器，会切到该会话的第一个浏览器标签再取。页面加载期间按钮会变灰，加载完成后再启用。

### 剪藏文件里有什么

文件名以本地时间开头，格式是 `YYYY-MM-DD_HH-mm-ss_页面标题.md`，例如 `2026-11-14_17-32-05_深度学习入门指南.md`。同一页面多次剪藏会按时间排序，不会互相覆盖；极端情况下同一秒内同名文件会追加 ` (2)`。

Markdown 文件的 frontmatter 固定只有四个字段，顺序如下：

```yaml
---
title: "..."
url: "..."
clipped_at: 2026-11-14T12:30:00+08:00
note: "Web snapshot generated by DSH Web Clipper. If the content is incomplete, revisit the original page."
---
```

| 字段 | 含义 |
|---|---|
| `title` | 页面标题；标题为空时回退到页面 URL |
| `url` | 跳转完成后的最终地址 |
| `clipped_at` | 开始抓取时本机的系统时间，带数字时区偏移 |
| `note` | 固定英文提示，告诉 Agent 内容不完整时回看原网页 |

不写站点、作者、发布时间、语言、字数或抓取模式。`note` 只放在元数据里，不会出现在正文。

提取不出正文时，文件变成 `.html` 整页快照，四个字段以 JSON 放在 doctype 之后的 HTML 注释里：

```text
<!-- dsh-clip: {"title":"...","url":"...","clipped_at":"...","note":"..."} -->
```

页面超过 4 MB 时只保留可见文本，仍然生成带同样四个字段的 `.md`。

## 故障排查

| 现象 | 先查 |
|---|---|
| 两个入口都不出现 | 是否在桌面版。Web 版没有桌面侧栏浏览器，插件不显示入口 |
| 点击后提示「没找到可添加的网页」 | 先在侧栏浏览器打开一个 `http(s)` 页面，`about:` 空白页不算 |
| 点击后提示「页面还在加载」 | 等页面加载完成再点一次 |
| 点击后提示「输入框正忙」 | 输入框正在发送或锁定，稍后再点 |
| 附件里正文不完整 | 站点结构特殊时提取会降级。用整页 `.html` 快照，或按 `note` 的提示回看原网页 |
| 页面很大，只得到纯文本 | 超过 4 MB 的页面按设计只保留 `innerText`；附件里仍有标题与来源 URL |
| 提示「可读副本未保存」 | 检查设置里的目录是否存在、是否有写权限；附件已经加入会话，不影响继续使用 |
| 找不到副本 | 在插件设置里点「打开文件夹」；默认目录是系统临时目录下的 `dsh-web-clipper` |
| 详情页同时显示 `dsh-web-clipper` 和 `@westwall/dsh-web-clipper` | 前者是插件行 ID，后者是 npm 包名，不是装了两次 |

## 卸载与清理

```sh
dsh plugin --profile <profile> remove @westwall/dsh-web-clipper
```

插件不额外保存索引或站点凭据。已经加入输入框的附件属于当前会话，删除附件即可；已经写出的可读副本留在原目录，需要时手动清理。通过「资讯工作台」安装时剪藏是随附行，卸载资讯工作台即可一并移除。不要同时把「资讯工作台」和「网页剪藏」作为两个 bundle 安装，否则同一插件行会挂两次。
