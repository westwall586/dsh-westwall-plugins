3. 基线

3.1 什么是基线

基线是最近一次已发送、且留下了全文快照的审阅轮次。发送后，Host 把当时的 .md 存成快照。

只标记本次批注提交后仍存在且被更新的段落与组件，并在目录里标出被更新的章节。

3.2 为什么快照缺失时不回退

最新一轮没有快照就不显示更新，不向更早的轮次回退。否则基线会悄悄变旧。

4. Host 接口

只加一个只读接口：reviewLatest 返回快照与元数据；缺失就返回空。
