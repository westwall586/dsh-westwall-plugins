# 可交互 Markdown 使用手册

> **状态：草稿。** 尚未发布，推荐用本地目录或固定提交安装。阅读渲染与翻译主流程已在 Web 版实机验证；P1.1 的取消、保存规则与标题校验已由单测覆盖，待实机复核。

原生的 Markdown 预览把长文当成一页文本，英文文档也没有可切换的中文视图。可交互 Markdown 接管右侧栏正文，按块渲染标题、列表、表格、代码与图片；点「译文」按行号与标题层级对齐翻译，翻译中可取消，右键任意一行查看该行原文，保存后译文留在工作区。原文文件永远不会被改写。

## 快速开始

1. 安装插件：

   ```sh
   dsh plugin --profile <profile> add link:/绝对路径/packages/active-markdown
   ```

2. 重启 DSH，或等待桌面版热加载完成。
3. 从右侧栏「工作区文件」打开任意 `.md` 文件。预期结果：正文由可交互 Markdown 渲染，右上角「打开方式」显示「可交互 Markdown」。
4. 点工具栏的「译文」。预期结果：状态行显示「正在翻译…」，完成后正文换成译文。首次翻译不会自动发生，必须点「译文」。翻译中可点「取消」，取消会中止本次模型调用并回到原文。
5. 打开侧栏「插件」，在「已安装插件」里点「可交互 Markdown」，页面上会出现「翻译设置」。模型、目标语言与代码注释都在这里配置。

## 配置

| 项 | 说明 |
|---|---|
| 翻译模型 | 默认跟随会话默认模型。取消「跟随会话默认模型」后，填写 provider 与模型名。 |
| 目标语言 | 默认 `zh`（简体中文）。可选 `zh-Hant`（繁體中文）与 `en`（English）。选项存语言代码，不存显示名。 |
| 翻译代码围栏里的注释 | 默认开启。关闭后，代码围栏内的注释也逐字保留，整段代码不译。 |

设置在每次翻译开始时读取。保存后，下一次翻译生效；已经显示的译文不会自动重译，需要点「重新翻译」。

## 日常使用

### 切换原文与译文

1. 打开文档后默认显示「原文」。
2. 点「译文」，插件翻译整篇文档，并按行数和标题层级对齐。
3. 再点「原文」或「译文」只切换视图，不重新请求模型。
4. 同一份文档再次打开时，自动缓存或已保存的译文直接可用，不发请求。

长文档会按章节顺序分块翻译。状态行显示当前块与总块数，已完成的块先显示，未完成的块保留原文行，所以页面在翻译过程中仍可阅读。

翻译中可点「取消」。取消会中止正在进行的模型调用，丢弃已收到的内容并回到原文，不写自动缓存。

### 查看某一行原文

1. 在「译文」里右键任意一行，选择「查看原文」。
2. 浮窗只显示该行的原文，标题写「第 N 行」。点另一行，浮窗跟过去。
3. 点浮窗外的空白、按 Esc、滚动正文、切换视图或重新翻译，浮窗关闭。

逐行对照依赖行数一致，并且每个标题的层级与所在行都与原文相同。行数或标题对不上时，浮窗与行号列整体停用，不会把不相关的原文配给这一行。

### 重新翻译

1. 译文完成后，点「重新翻译」。
2. 可以留空，也可以写一句补充要求，例如「术语保留英文」。
3. 点「重新翻译」后覆盖旧结果与旧缓存，旧版本不保留。

### 保存译文

1. 译文完成后，点「保存」。自动缓存里的译文也可以保存；已经保存过的译文不再显示「保存」。
2. 保存写两份文件。正文放在 `.dsh-active-markdown/translate/<语言代码>/<源文件相对路径>`，元数据放在平行的 `.dsh-active-markdown/index/translate/<语言代码>/` 下，把正文路径的最后一个扩展名换成 `.json`。
3. `docs/a/README.md` 翻译成简体中文后，正文是 `.dsh-active-markdown/translate/zh/docs/a/README.md`，元数据是 `.dsh-active-markdown/index/translate/zh/docs/a/README.json`。文件名与源文件一致，语言只是目录。
4. 工作区外的文档（例如绝对路径的会话文件）没有相对路径可镜像，落在 `translate/<语言代码>/_external/<路径 sha1 前 8 位>/<文件名>`，元数据在 index 树的同一位置。
5. 不同目录的同名 `README.md` 各自保存；同一份文档换语言保存到不同语言目录，互不覆盖。
6. `.dsh-active-markdown/.gitignore` 忽略该目录下的全部内容，`git status` 不会因为翻译变脏。

自动缓存放在插件存储里，不落工作区。它是可丢的，删掉只是下一次重新翻译。「保存」才会把译文写进工作区。自动缓存按整篇保存，单份译文上限 4 MiB。原文在保存后改过时，旧译文仍可查看，但不再显示保存入口；先点「重新翻译」再保存。

## 已知限制

- 逐行对照的前提是译文行数与原文行数完全一致，并且每个标题的层级与所在行都与原文相同。模型漂移时，译文仍然可读，也可以保存，但逐行浮窗与行号列会停用，状态行会提示「行数不一致」或「标题不一致」。分块能降低漂移概率，不能消除。
- 一份漂移的译文会以「未对齐」状态回来。点「重新翻译」再试一次，通常就能恢复；插件不会静默重试，也不会自动重译。
- 自动缓存按整篇保存，单份译文上限 4 MiB。超过上限的译文仍可阅读与保存，只是不会进入自动缓存。

## 故障排查

| 现象 | 先查 |
|---|---|
| 没有「译文」按钮 | 「打开方式」里是否选了「可交互 Markdown」；插件是否已启用 |
| 提示「未配置翻译模型」 | 在「翻译设置」里选择模型，或在会话里设置默认模型 |
| 状态行提示「行数不一致」或「标题不一致」 | 模型漂移；点「重新翻译」，长文档可再试一次 |
| 翻译中点「取消」后没有译文 | 本次模型调用已中止并按设计回到原文；需要时再点「译文」 |
| 右键没有「查看原文」 | 当前译文未对齐；重新翻译后再看 |
| 保存失败 | 工作区是否可写；源路径是否包含 `..`；磁盘是否已满 |
| 找不到 `.zh.md` 文件 | 语言现在是目录，不是文件名后缀；到 `.dsh-active-markdown/translate/zh/` 下找 |
| 换了目标语言后没有译文 | 译文按语言分开保存与缓存；点「重新翻译」 |
| 提示「原文已更新」 | 源文件在保存后改过；旧译文仍可看，保存入口已隐藏，点「重新翻译」覆盖 |

## 卸载与清理

```sh
dsh plugin --profile <profile> remove @westwall/dsh-active-markdown
```

卸载并重启后，`.md` 恢复原生预览。插件不修改原文；要清理产物，删除工作区里的 `.dsh-active-markdown/` 目录即可。插件存储里的自动缓存也可以删除，删掉只会让下一次翻译重新请求模型。
