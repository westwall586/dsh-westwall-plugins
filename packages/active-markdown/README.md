# 可交互 Markdown 使用手册

> **状态：草稿。** 尚未发布，推荐用本地目录或固定提交安装。阅读渲染与翻译主流程已在 Web 版实机验证；P2 批注、反馈附件、审阅快照与发送后的更新标记已实现并由单测覆盖；P4e 数学公式已实现并由单测覆盖，公式观感待 Web 复核；Web 版交互已按 P2 UI 重排完成一轮实机复核，桌面版待复核。

原生的 Markdown 预览把长文当成一页文本，英文文档也没有可切换的中文视图。可交互 Markdown 接管右侧栏正文，按块渲染标题、列表、表格、代码与图片。`> [!note] 标题` 这类 Callout 按语义色渲染，front matter 显示成两列元信息卡，点图可放大，代码块带语法高亮并可切换换行。表格、代码块、公式、Mermaid 与思维导图共用一套组件外壳，顶栏右侧是换行（仅代码）、复制、批注、全屏四个图标按钮；Mermaid 与思维导图点内容即可进全屏，弹框里可拖动、缩放，比例以适配为 100%，代码块在弹框里保留当前的换行偏好。文档里的链接不会把你踢出应用：外部链接在右侧栏的浏览器页签打开，文件与图片链接在侧栏预览，宿主没有侧栏浏览器时退回系统的新标签页。Mermaid 图与 Markmap 式思维导图按需加载，宽度跟随正文；渲染失败时显示源码与错误首行。行内 `$…$`、行间 `$$…$$` 与 ```` ```math ```` 公式用 KaTeX 渲染，观感与聊天里的公式一致，同样按需加载；公式写坏时回退成源码。点工具栏的「翻译」进入翻译模式，插件分块翻译整篇文档；翻译模式只保留返回原文、目录、语言、重新翻译与保存，没有行号、批注和更新标记。译文里选中文字后右键可查看对应原文。原文里选中文字后右键批注，表格与代码块可从右上角整块批注；工具栏的「批注 N」打开抽屉，或直接点「加入对话」把这一轮反馈加入输入框。反馈由你确认后发送，发送成功清空这一轮批注，并把发送前的全文快照留在工作区。原文文件永远不会被改写。发送过反馈后，Agent 再改文件时，工具栏的「更新 N 处」、正文左侧刻度（组件也画在正文页边，与标题行对齐）与目录条目右端的圆点指出需要重读的地方。

## 快速开始

1. 安装插件：

   ```sh
   dsh plugin --profile <profile> add link:/绝对路径/packages/active-markdown
   ```

2. 重启 DSH，或等待桌面版热加载完成。
3. 从右侧栏「工作区文件」打开任意 `.md` 文件。预期结果：正文由可交互 Markdown 渲染，右上角「打开方式」显示「可交互 Markdown」。
4. 点工具栏右侧的「翻译」。预期结果：进入翻译模式，工具栏改为「原文、目录、语言、重新翻译、保存」，翻译中显示当前块与总块数。完成后正文换成译文。首次翻译不会自动发生，必须点「翻译」。翻译中可点「取消」，取消会中止本次模型调用并回到原文。
5. 打开侧栏「插件」，在「已安装插件」里点「可交互 Markdown」，页面上会出现「翻译设置」。模型、目标语言与代码注释都在这里配置。

## 配置

| 项 | 说明 |
|---|---|
| 翻译模型 | 默认跟随会话默认模型。取消「跟随会话默认模型」后，填写 provider 与模型名。 |
| 目标语言 | 默认 `zh`（简体中文）。可选 `zh-Hant`（繁體中文）与 `en`（English）。选项存语言代码，不存显示名。 |
| 翻译代码围栏里的注释 | 默认开启。关闭后，代码围栏内的注释也逐字保留，整段代码不译。 |

设置在每次翻译开始时读取。保存后，下一次翻译生效；已经显示的译文不会自动重译，需要点「重新翻译」。

## 日常使用

### 进入与退出翻译模式

1. 打开文档后默认显示原文。
2. 点「翻译」进入翻译模式；插件翻译整篇文档，完成后正文换成译文。
3. 点左上角「原文」退出翻译模式，不重新请求模型；再次点「翻译」时，自动缓存或已保存的译文直接可用。
4. 同一份文档再次打开时，自动缓存或已保存的译文直接可用，不发请求。

长文档会按章节顺序分块翻译。翻译模式顶部显示当前块与总块数，已完成的块先显示，未完成的块保留原文行，所以页面在翻译过程中仍可阅读。翻译模式没有行号，也没有「已对齐」状态。

翻译中可点「取消」。取消会中止正在进行的模型调用，丢弃已收到的内容并回到原文，不写自动缓存。

### 查看选中文字的原文

1. 在翻译模式里选中一段文字（同一行或跨行），右键「查看原文」。
2. 浮窗显示选区覆盖的原文行；单行标题写「第 N 行」，跨行写行号范围。
3. 点浮窗外的空白、按 Esc、滚动正文、切换视图或重新翻译，浮窗关闭。

逐行对照依赖行数一致，并且每个标题的层级与所在行都与原文相同。行数或标题对不上时，右键里不会出现「查看原文」，页面也不会显示行号列或对齐状态，不会把不相关的原文配给这一行。

### 批注

1. 在「原文」里选中任意连续文字（同一行、跨行、跨文本块），右键「批注」，在输入框里写意见。没有标签、优先级或状态，只有意见本身。
2. 表格、代码块、公式这类组件在右上角有「批注」，打开浮窗写意见。一个组件只保留一条批注；已经有批注时，按钮变成「编辑批注」。浮窗点空白处或按 Esc 收起，`Cmd/Ctrl+Enter` 保存。
3. 工具栏的「批注 N」打开抽屉。抽屉里可以定位、编辑、删除、撤销删除与清空；按标题路径分组，单条显示所在行与原文。
4. 翻译模式不提供批注入口，也不能新建、编辑或删除批注；在译文里选中文字右键，只出现「查看原文」与「复制」。
5. 选区跨进表格、代码块或公式块时，插件不会把文字硬塞进组件；提示「选区包含组件，请单独批注该组件」。
6. 批注按会话与文档持久化，刷新页面或重启 DSH 后仍在。草稿最多保留 20 份文档、30 天，超出后按最后更新时间淘汰。

### 把反馈发给 Agent

1. 在抽屉里点「加入对话」，或直接点工具栏右侧的「加入对话」。插件生成 `<文档名>-review-<roundId>.md`，作为普通文件附件加入输入框，并把焦点放回输入框；它不会自动发送，也不会把反馈插成聊天文本。
2. 检查附件和输入框后，自己点发送。只有同时满足以下条件的附件才算这次批注的反馈：草稿里还有这份文档的待发送记录、输入框里有这个附件 id、附件名/字节数/SHA-256 与记录一致、发出的消息里出现对应 `FileBlock`。Web Clipper 或其他手工附件不参与判定。
3. 发送成功：清空这一轮冻结进反馈文件的批注与待发送记录；发送后新加的批注会留下，作为下一轮草稿。发送失败：附件和批注都保留，可以重试；手动把附件从输入框移除只清掉待发送记录，批注保留。
4. 加入对话后继续改批注，插件会用同一个 `roundId` 重做反馈文件，先加新附件再移除旧附件。发送中的批注编辑会被拦住，避免把发送后才写的意见算进这一轮。
5. 同一份文档同时只保留一个反馈附件。原文在加入后发生变化时，插件不会悄悄把快照换成新原文；先移除当前附件，再点「加入对话」，会以新原文开始新一轮。
6. 发送前的全文快照先写到 `.dsh-active-markdown/reviews/pending/<roundId>.md`；发送成功后转到 `.dsh-active-markdown/reviews/<源文件相对路径>/<roundId>.md`，旁边写同名 `.json` 元数据。工作区外的文档落在 `_external/<路径 sha1 前 8 位>/`。
7. 审阅快照每个文档保留最近 5 轮，另受 30 天与全局 50 MiB 限制；每个文档最新一轮不淘汰。发送时快照缺失不会阻止发送，元数据会标 `snapshotMissing`。

### 查看上次反馈后的更新

1. 发送过一轮反馈后，Agent 改动文件，工具栏出现「更新 N 处」。N 是新增或修改的顶层块数量，不拆分新增与修改，也不统计删除。
2. 被更新的段落、标题、表格、代码块左侧有 3px 刻度标记；删除的内容不生成 ghost，也不占位。
3. 点「更新 N 处」会跳到下一处更新，序号变成 `1/N`、`2/N`…，走完一轮后回到第一处；目标块会短暂高亮。
4. 工具栏「目录」列出文档顶层的 H1–H6 标题，默认全部展开，按层级缩进。有章节更新时按钮带小圆点；打开目录浮层后，被更新章节的条目在右端带圆点，点条目跳到对应标题。折叠与当前章节的细节见下一节。
5. 有未发送的反馈附件时先不显示更新。发送成功或把附件从输入框移除后，按最近一次已发送的轮次重新计算。翻译模式不显示更新与批注，但有自己的目录浮层，目录只列当前译文的标题。
6. 基线只认最近一次**已发送**且全文快照存在的轮次。最新一轮快照缺失时不显示更新，不会回退到更早的轮次。

### 目录

1. 点工具栏的「目录」打开浮层，再点一次或按 Esc 关闭。
2. 有下级标题的行首有箭头。点箭头只折叠或展开这一组，不跳转、不关闭浮层；点标题文字跳到对应标题并关闭浮层。
3. 浮层默认全部展开。折叠状态在关闭重开后保留；切换文档或原文与译文视图会重置。
4. 阅读位置对应的条目前有 2px 竖条。当前章节被折叠时，高亮最近的可见父标题，不会自动展开。
5. 浮层宽度跟随预览栏：窄栏里收缩到栏内，不会溢出到正文外。
6. 译文视图的目录只列当前译文的标题，不带更新圆点，同样支持折叠与当前章节。

### 打开链接与全屏

1. 外部链接（http、https、mailto）在右侧栏的浏览器页签打开，文档留在原处；宿主没有侧栏浏览器时改开系统的新标签页。
2. 相对文件链接按文档所在目录解析，在右侧栏预览目标文件；图片作为链接目标时同样开预览，不打开图片灯箱。`#标题` 链接在当前文档内跳转。
3. 表格、代码块、公式、Mermaid 与思维导图共用一套组件外壳，顶栏右侧是同一组图标按钮：换行（仅代码）、复制、批注、全屏；公式块只有复制与批注，没有全屏。点全屏把该组件放到居中弹框，Esc、点遮罩或关闭按钮都能退出，退出后焦点回到全屏按钮。弹框里的批注按钮打开贴在右侧的批注抽屉，抽屉按面板布局，Esc 先收抽屉并把焦点还给批注按钮，再按一次才关弹框；点抽屉外的面板正文也能收起。
4. Mermaid 与思维导图点内容即可打开弹框，聚焦后按 Enter / Space 也能打开。弹框底部是「−、百分比、+、适配、实际大小」，百分比以适配为 100%，拖动与滚轮可以平移缩放。代码块在弹框里沿用当前的换行偏好，缩放不适用于代码块与表格。

### 阅读公式

1. 行内 `$…$`、行间 `$$…$$` 与 ```` ```math ```` 围栏都按公式渲染，观感与聊天里的公式一致。第一次出现公式时才加载包内的 `client.math.js`；没有公式的文档不会为它多加载一个字节。
2. 公式块与表格、代码块共用一套组件外壳，右上角有复制与批注，没有全屏；宽公式在组件框里横向滚动。
3. 行内公式写坏时保留 `$…$` 源码，段落其余部分照常显示；行间公式写坏时显示源码、错误首行与「复制错误」，不白屏。
4. 公式不参与翻译：提示词要求行内与行间公式逐字保留，译文里仍按原文渲染。

### 重新翻译

1. 译文完成后，点「重新翻译」。
2. 可以留空，也可以写一句补充要求，例如「术语保留英文」。
3. 点「重新翻译」后覆盖旧结果与旧缓存，旧版本不保留。

### 保存译文

1. 译文完成后，点右侧的「保存」。保存中按钮显示「保存中…」，成功后变成禁用的「已保存」。自动缓存里的译文也可以保存。
2. 保存写两份文件。正文放在 `.dsh-active-markdown/translate/<语言代码>/<源文件相对路径>`，元数据放在平行的 `.dsh-active-markdown/index/translate/<语言代码>/` 下，把正文路径的最后一个扩展名换成 `.json`。
3. `docs/a/README.md` 翻译成简体中文后，正文是 `.dsh-active-markdown/translate/zh/docs/a/README.md`，元数据是 `.dsh-active-markdown/index/translate/zh/docs/a/README.json`。文件名与源文件一致，语言只是目录。
4. 工作区外的文档（例如绝对路径的会话文件）没有相对路径可镜像，落在 `translate/<语言代码>/_external/<路径 sha1 前 8 位>/<文件名>`，元数据在 index 树的同一位置。
5. 从文档内链接打开的文件地址是绝对路径；保存时归一成相对路径，和从侧栏打开时落在同一镜像位置，不会存成两份。
6. 不同目录的同名 `README.md` 各自保存；同一份文档换语言保存到不同语言目录，互不覆盖。
7. `.dsh-active-markdown/.gitignore` 忽略该目录下的全部内容，`git status` 不会因为翻译变脏。

自动缓存放在插件存储里，不落工作区。它是可丢的，删掉只是下一次重新翻译。「保存」才会把译文写进工作区。自动缓存按整篇保存，单份译文上限 4 MiB。原文在保存后改过时，旧译文仍可查看，工具栏显示「译文已过期」，保存入口隐藏；先点「重新翻译」再保存。

### 编辑原文与保存

1. 点工具栏「编辑」，正文换成源码编辑器：左侧行号，Markdown 语法高亮，顶部工具栏变成「行数 / 保存 / 退出」。
2. 入口只对**工作区内**、当前会话可写、1 MiB 以内的普通 Markdown 文件出现。符号链接、工作区外文件、只读会话与超大文件不显示「编辑」，阅读与批注照旧。
3. 有未发送的批注时不能进入编辑，点「编辑」会提示先发送或丢弃。编辑中没有批注、翻译与目录入口。
4. `Cmd/Ctrl+S` 或点「保存」写回原文件。保存成功后回到阅读视图，渲染结果立刻更新，目录、更新标记与译文过期状态按新内容重算。
5. 保存带版本守卫。文档打开后如果被 Agent 或别的程序改过，保存会弹冲突面板，给三个出口：「重载（丢弃我的修改）」看磁盘上的新版本；「覆盖」二次确认后用你的内容覆盖对方的改动；「另存为」把当前草稿写成**原文件同目录**的 `<文档名>.conflict-<日期>-<时间>.md`，提示里有完整路径和「复制路径」，原文件随后重载。另存为的文件在文件树里可见。
6. 误关冲突面板不会丢草稿：面板关掉后仍是编辑态，可以接着改、再保存。
7. 有未保存改动时点「退出」或按 Esc 会先确认，选「放弃修改」才退出。草稿只在内存里，刷新页面或换文档即丢。
8. 保存后原来的译文按新的原文标过期，需要重新翻译；插件不会自动重译，也不会改写译文文件。

## 已知限制

- 逐行对照的前提是译文行数与原文行数完全一致，并且每个标题的层级与所在行都与原文相同。模型漂移时，译文仍然可读，也可以保存，但右键不会出现「查看原文」；页面不显示对齐状态。分块能降低漂移概率，不能消除。
- 一份漂移的译文需要点「重新翻译」再试一次，通常就能恢复；插件不会静默重试，也不会自动重译。
- 自动缓存按整篇保存，单份译文上限 4 MiB。超过上限的译文仍可阅读与保存，只是不会进入自动缓存。
- 文本批注只覆盖正文里的连续文字；表格、代码块与 Callout 按整个组件批注，不能只批注其中一格、一行代码或 Callout 里的一句话。选区跨进组件时必须单独批注组件。
- Callout 只认 13 个规范类型与别名；未知类型、`-`/`+` 折叠语法、列表内与嵌套引用都按普通引用显示。front matter 卡片不做 YAML 语义，嵌套结构只按缩进续行并入上一条，不展开成层级。
- Mermaid 与思维导图是只读渲染：文档里第一次出现时才加载包内的 `client.mermaid.js` / `client.markmap.js`；导图初始展开两层，折叠、拖拽与缩放不写回文档。图渲染失败时只能看源码与复制错误，不能在阅读页里改图。
- 公式也是只读渲染：文档里第一次出现公式时才加载包内的 `client.math.js`。公式的字与样式来自宿主全局加载的 KaTeX 样式表，插件不打包 CSS 与字体，宿主换渲染方案时公式会退到系统衬线。
- 含行内公式的一行里做文本批注时，选区偏移按公式的 TeX 源码计长，与屏幕上渲染后的字宽不一致，批注可能落在附近；行间公式是组件，选区跨过它时只能整块批注。
- 公式不参与翻译：提示词第 2 版要求行内与行间公式逐字保留；自动缓存按提示词版本区分，升级后旧的缓存不再命中，再翻译一次才会套用新规则。
- 翻译模式不允许批注，也没有更新标记；可以打开译文自己的目录。翻译模式不显示行号，也不提供源码编辑；要编辑先切回原文。
- 发送判定依赖 DSH 的输入框阶段与消息里的文件块。附件被手动移除时插件会保留批注，不会猜测“可能已经发送”。
- 更新标记只到顶层块：列表或引用内部有变化时整块标记；新增与修改不区分；删除不展示。
- front matter 的变化不计数；同一块只移动位置不算更新。
- 目录只列文档顶层的 H1–H6 标题。引用或列表里的标题不进目录，但仍可在正文里被标记。目录的折叠与当前章节只影响浮层；正文不折叠，也不在页面上常驻显示当前章节。切换文档或原文与译文视图会重置折叠。
- 更新基线只认最近一次已发送的轮次。最新快照缺失时不显示更新，不会回退；损坏的轮次元数据会被跳过，可能落到更早的可读轮次。
- 编辑只覆盖整篇源码，没有所见即所得与块级编辑；代码块在阅读页有语法高亮，编辑页仍用编辑器的 Markdown 高亮。
- 代码块由平台共享的代码组件渲染，行不再有独立的行号标记：译文里选中代码块中的文字，右键不再出现「查看原文」；批注与更新标记仍落在整个代码块，不能定位到其中一行。
- 全屏是阅读视图：弹框头部保留批注与复制按钮，批注在右侧抽屉里编辑，不提供源码编辑；Mermaid 与导图可以拖动、滚轮缩放，代码块与表格不缩放。关闭后回到组件顶栏。窄屏下弹框按可用宽度收缩，表格在弹框里仍横向滚动。
- 编辑入口只对工作区内文件出现，因为会话的写权限按工作区围栏，工作区外的写会被宿主拒绝。插件不会为了编辑去放宽会话权限。
- 编辑保存后，你自己改的那些块也会算进「上次反馈后更新了 N 处」；插件不区分「你的修改」与「Agent 的修改」。
- 「另存为」的文件名固定为 `<文档名>.conflict-<日期>-<时间>.md`，不能让用户另选目录或文件名。

## 故障排查

| 现象 | 先查 |
|---|---|
| 没有「翻译」按钮 | 「打开方式」里是否选了「可交互 Markdown」；插件是否已启用 |
| 提示「未配置翻译模型」 | 在「翻译设置」里选择模型，或在会话里设置默认模型 |
| 翻译中点「取消」后没有译文 | 本次模型调用已中止并按设计回到原文；需要时再点「翻译」 |
| 右键没有「查看原文」 | 当前译文未对齐；重新翻译后再看 |
| 右键没有「批注」 | 是否在原文视图、是否选中了非空文字；选区跨进表格/代码块时不能批注文字 |
| 「加入对话」是灰的 | 发送中或命令提交中；没有批注；当前会话不支持文件附件；这一轮已经加入过 |
| 发完消息批注还在 | 检查消息里是否真的有该反馈附件；插件只在四者匹配时清空，手动移除附件会保留批注 |
| 提示「原文已变化」 | 先移除当前反馈附件，再点「加入对话」以新原文开始一轮 |
| 刷新后批注没了 | 插件存储是否被清理；草稿有 20 份/30 天上限；存储不可用时只保留在内存 |
| 工具栏出现「保存失败」 | 点开红色提示看完整错误；检查工作区是否可写、源路径是否包含 `..`、磁盘是否已满，再点「重试」 |
| 找不到 `.zh.md` 文件 | 语言现在是目录，不是文件名后缀；到 `.dsh-active-markdown/translate/zh/` 下找 |
| 换了目标语言后没有译文 | 译文按语言分开保存与缓存；点「重新翻译」 |
| 提示「译文已过期」 | 源文件在保存后改过；旧译文仍可看，保存入口已隐藏，点「重新翻译」覆盖 |
| 工具栏没有「更新 N 处」 | 是否发送过一轮反馈；是否有未发送的附件；文件是否与最近的快照相同；最新快照是否缺失 |
| 目录没有更新圆点 | 最近一轮是否已发送；更新是否只删除了内容；文件是否已改回基线 |
| 标记落在整段而不是某一行 | 标记粒度是顶层块；换行、列表符号变化不算更新，链接、图片、强调变化算更新 |

## 卸载与清理

```sh
dsh plugin --profile <profile> remove @westwall/dsh-active-markdown
```

卸载并重启后，`.md` 恢复原生预览。插件不修改原文；要清理产物，删除工作区里的 `.dsh-active-markdown/` 目录即可，翻译镜像与审阅快照都在这里。批注草稿与自动缓存放在插件存储里，删掉只会让下一次重新读取或翻译；草稿本身按 20 份文档/30 天自动清理，审阅快照按 5 轮/30 天/50 MiB 自动清理。
